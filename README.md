# Auger Client: 7 Days to Die Player Mod Sync App

> **For players joining modded 7 Days to Die servers hosted with Auger**  
> Hosting a dedicated server instead? Download **Auger Server Manager** from [**RBND/Auger-Releases**](https://github.com/RBND/Auger-Releases/releases/latest).

**Auger Client** is a lightweight, portable desktop app for Windows and Linux that automatically checks, downloads, and installs the exact mods required to join an Auger-hosted 7 Days to Die server, then launches the game with the right Anti-Cheat setting.

---

## Download Latest Release

Head to the [**Latest Release**](https://github.com/RBND/Auger-Client-Releases/releases/latest) page and grab the zip for your OS:

- **Windows**: `AugerClient-vX.Y.Z-Win.zip` (unzip and run `Auger-Client.exe`)
- **Linux**: `AugerClient-vX.Y.Z-Linux.zip` (unzip, `chmod +x Auger-Client`, and run `./Auger-Client`)

Also available on [**Nexus Mods**](https://www.nexusmods.com/7daystodie/mods/14184).

---

## How It Works

1. Open **Auger Client**.
2. Paste the server's **Mod Sync address** (for example `https://7.rbnd.cc`) and click **Sync mods**.
3. Click **Play** to launch 7 Days to Die and join the server automatically.

Your personal client mods stay safe and can be toggled on or off anytime under **My mods**.
